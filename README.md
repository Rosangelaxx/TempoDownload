# TempoDownload

Aplicação em C# para estimar o tempo de download com base no tamanho do arquivo e na velocidade da conexão.

## Como usar

1. Execute o programa.
2. Informe o tamanho do arquivo em MB.
3. Informe a velocidade da conexão em Mbps.
4. O programa calcula o tempo estimado em minutos.

## Exemplo

- Tamanho: 120 MB
- Velocidade: 50 Mbps
- Resultado: aproximadamente 19,2 minutos
